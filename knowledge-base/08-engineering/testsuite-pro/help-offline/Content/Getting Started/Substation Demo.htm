Substation Demo with DTM and TSP

Distributed Test Manager (DTM) is a Windows® application that can simulate the SCADA communications in the substation and perform automated tests to confirm system or individual device behavior. TSP and DTM are both part of the System Toolkit that facilitates the IEC 61850 Engineering Process as explained in this video. If you do not already have DTM installed, download an evaluation version of DTM HERE. If the trial license does not install automatically, you may request a Trial Activation Key by sending an email to: support@trianglemicroworks.com .

The Demo Substation

The substation in the demo is the high voltage part of a substation with two lines and two transformer bays connecting to a single busbar. In each bay, we have a protection device and a bay control unit.

The bay control unit implements the control and interface to the breakers and switches and provides the measurements. It receives trips from the protection using GOOSE. The protection device implements the protection functions including breaker failure and trips the breakers through the bay control unit. For the line bay, the protection device is as well implementing the synchrocheck and reclosing function.

Setup

First, run the DTM Configuration Tool and set your Adapters. Make sure to select a GOOSE adapter. It is important to select an adapter that is on a network where GOOSE messages will not interfere with other machines or devices. A good option is to use a loopback adapter for GOOSE messaging so the GOOSE messages do not flood onto the network. This entire example can be run loopback on the same machine between DTM and TSP.

Next, open DTM and click on Load Sample Workspace from the DTM Start Page:

Then select the workspace named “IEC 61850 Substation Demo”:

From there, allow the workspace to fully load. Keep in mind that you will likely have warning messages that none of the devices are connected:

In DTM, right-click on the Script named “Start Simulation.js” in the workspace and select "Start/Execute Scripts".

Now open TSP and select the workspace named “Substation GOOSE Demo for TSP – Loopback”:

In TSP, navigate to the Signal Flow Display on the right. Make sure the "Recloser Operation" layout is selected, as shown here:

In TSP, click on the Record button to start recording signals. *You may receive a message that some of the signals did not have initial values. This is ok.

Now in DTM, click on the PDIF1 button to initiate a fault. This will create an operate of the protection differential element, which will result in a trip generated by PTRC. The trip will be sent with a GOOSE message to the LN XCBR in the bay controller which will open the breaker. At the same time, the trip was internally sent as a initiate signal to the reclosing and the breaker failure function. After a while, the reclosing function will reclose the breaker through the LN CSWI (note the assumption here is, that the reclosing needs to be done with synchrocheck). If release from synchrocheck (LN RSYN) is true, the CSWI will reclose the breaker through the LN XCBR. By default, the fault is assumed to not be permanent, so the reclosing will be successful. You can activate the checkbox next to the PDIF1 button in DTM, which will make the fault permanent. Following a permanent fault which makes the reclose to fail, you can reset the simulation pushing the reset simulation button in DTM.

Over in TSP, you will see that Signal Flow has 12 events. Stop the recording and step through the events one at a time using the button to the right of the stop button. Hover the mouse over each event on the Timeline to read a description or hover over a signal to see a list of events for that signal.
