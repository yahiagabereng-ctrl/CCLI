Publishing GOOSE Messages

There are two ways to publish GOOSE messages:

  • GOOSE Publisher - used to manually publish specific GOOSE control blocks with access to change the header and data. Invalid header values are allowed for negative testing including incorrect state and sequence numbers.
  • IED Simulator - used to simulate the MMS and GOOSE communications for an IED. All GOOSE correctly configured control blocks for an IED are automatically published when the IED Simulator is started. Any data changes made to the data in the dataset will be published as a valid state change automatically.

GOOSE Publisher

Publish a GOOSE Control Block

Follow these steps to publish a single GOOSE control block:

1) Create a workspace using an SCL File that has a GOOSE control block

2) Go to the GOOSE Publisher tool

3) Select an Ethernet Adaptor from where the GOOSE messages will be published

4) Select a GOOSE Control Block to load GOOSE configuration information

5) Select "Start Publishing" to start sending the GOOSE messages

GOOSE messages will then be published using the parameters in the GOOSE header configuration and current values for DataSet members

Note: the GOOSE Publisher uses the same re-transmissions algorithm as the IED simulator according to the MinTime and MaxTime from the communication section of the SCL file. The Sequence Number, Time Allowed To Live, and Timestamp will automatically be updated in each re-transmission message sent.

Change GOOSE Header or DataSet Values

GOOSE header parameters and data values can be changed by following these steps:

1) Change any header parameters (note that changing header parameters is intended for negative testing or troubleshooting GOOSE subscribers)

2) Change any DataSet values

3) To start publishing GOOSE messages with the new header and data, press either:

"Increment State and Publish" - this will increment the state number (to indicate a state change in the DataSet) and then send the new message

OR

"Publish Current State" - this will send the new message without incrementing the state number

Note: the header parameters for Sequence Number, Time Allowed to Live, and Time Stamp cannot be manually set. These parameters are automatically set by the tool.

Tip: you can go back to the original GOOSE Control Block parameters from the SCL by selecting "Reload Header from GOOSE Control Block"

View Most Recently Published GOOSE

The most recently published GOOSE message is shown in the bottom half of the window. This allows you to confirm what GOOSE messages the tool is publishing.

Another option to view published GOOSE messages is to use the GOOSE Tracker which sniffs the network for GOOSE.

Tip: When the tool is publishing a GOOSE control block, the sequence number should increment each time a GOOSE re-transmission is automatically sent by the tool.

Publish Multiple GOOSE Streams

Multiple GOOSE control blocks can be published by repeating these steps:

1) Select another GOOSE control block

2) Select "Start Publishing"

Duplicate GOOSE Streams

To copy a GOOSE control block:

1) Select "Duplicate Stream" to copy the currently select GOOSE Control Block

2) Select the new GOOSE Control Block copy

3) Make changes to the GOOSE header parameters (to avoid having two identical GOOSE streams on the network)

4) Select "Start Publishing"

Tip: you can emulate both normal and simulated GOOSE streams for an IED and test equipment by duplicating a GOOSE control block and then changing the header parameters for "Simulate" to "True" in the header of the duplicated GOOSE control block. This would be done to test how subscriber IEDs respond to normal and simulated GOOSE messages in different modes (on, blocked, test, test-blocked).

Publish GOOSE with IED Simulator

To publish all the GOOSE control blocks for an IED:

1) Follow the steps for simulating an IED - the simulated IED will publish all the valid GOOSE control blocks in the IED data model

2) Select either "Send Simulated GOOSE Messages" or "Send Normal GOOSE Messages" (simulated GOOSE messages are typically sent by test equipment)

3) Find DataSet in the IED data model

4) Change data values in the GOOSE DataSet by either:

Manually change data values in the model view of the IED simulator

OR

Automatically change data values in the Server Data Simulation
