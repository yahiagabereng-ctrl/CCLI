View GOOSE on the Network

The GOOSE Tracker is used to sniff GOOSE streams on the network.

Start the Tracker

1) Select the GOOSE Tracker tool

2) Select which Ethernet adapter from your PC to use

3) Start Tracker

Viewing GOOSE Streams

After the GOOSE Tracker starts, the table of GOOSE streams will be updated to show current status. Here are some of the columns displayed:

  • Valid - if this equals "True", this indicates if messages from the GOOSE stream have been received and the stream has not timed out. If this is "False" it either indicates the stream has timed out (exceeded Time Allowed To Live) or no GOOSE messages on the network have matched the GOOSE configuration from the SCL files in the workspace.
  • Is Subscribed To - this indicates if 61850 Test Suite Pro has subscribed to receive GOOSE events for this stream. The GOOSE Event Viewer shows any received GOOSE events.
  • Num Timeouts - this indicates how many times the GOOSE stream has timed out
  • SCL/Wire/Match - this indicates if the GOOSE stream has been seen on the network and if it matches the SCL configuration:
    • "Match" indicates that the GOOSE stream on the wire has been matched to a GOOSE control block in the SCL file
    • "Wire" indicates that the GOOSE stream has been seen on the network but does not match any GOOSE control blocks in the SCL files in the current workspace
    • "SCL" means that this GOOSE control block has been found in an SCL File configuration in the workspace but has not been seen on the network
    • If there are two lines for the same GOOSE ID (one equals "Wire" and the other equals "SCL"), this could indicate that the IED GOOSE control block is mis-configured and the IED is publishing the wrong GOOSE.
  • Simulate - this indicates that the GOOSE stream is simulated and being published by test equipment (not the IED). A simulated GOOSE stream and the GOOSE stream from the real IED can be seen at the same time in the GOOSE Tracker.

One was been sniffed on the network ("Wire"). The other is a GOOSE control block found in the SCL File in the workspace ("SCL").

Verify Data Set for GOOSE Stream

You can verify that a GOOSE stream has the correct DataSet. The tool will automatically compare the DataSet in the model to the DataSet in the SCL file. Below are instructions on how to do this:

1) Go to the GOOSE Tracker

2) Select the adapter that you want to use

3) Select start

4) Then right click on the GOOSE stream you want to verify

5) Select "Verify DataSet" as shown below
