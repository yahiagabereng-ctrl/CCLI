How to map inverters (integrator)

  1. Edit apps/ccli/config/plant/PLANT_ASSIGNMENT_PLANE.csv: one INVnn.TotW + INVnn.Status row per inverter; set enabled=Y, modbus_slave_id (inverter unit ID), field_device (model).
  2. Keep the POC meter and inverters on different buses or unit IDs — a shared slave ID on one RS485 line will collide.
  3. Each inverter maps to one SGGMMXUn LN; GenPVMMXU1.TotW = sum of enabled inverters (AGGREGATE row). Add SGGMMXU3..n to the CID before claiming MMS for INV03+.
  4. Run python scripts/plant-map-validate.py then python scripts/plant-map-generate.py (writes YAML + this page’s plant_map.json).
  5. Redeploy the dashboard: lab/tg544-openwrt/deploy-zone-dashboard.ps1.
