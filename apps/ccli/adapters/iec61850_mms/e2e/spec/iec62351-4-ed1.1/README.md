# IEC 62351-4 Ed. 1.1 companion code components

This folder contains the downloaded IEC 62351-4 companion archive and its extracted ASN.1/XSD files. The raw archive was supplied from the SEK Svensk Elstandard free-download listing, under “IEC 62351-4:2020 {Ed 1.1} CSV, zip-fil”:

- https://elstandard.se/hamta-fritt-ovrigt/

The outer archive contains `iec62351-4{ed1.1}soft_suppl.zip`. The ASN.1/XSD files, `IECManifest.xml`, and `EULA.txt` were extracted from that inner support archive. The manifest names the code component `IEC_62351-4.ASN.1_XSD.full`, marks the files normative/full, and identifies IEC 62351-4:2018 dated 2018-04-19. Confirm that this component remains applicable to IEC 62351-4:2018+AMD1:2020 before freezing the production wire map.

The package's IEC code-component license terms are retained in `EULA.txt`, and the component notice is retained in `IECManifest.xml`. Preserve those files and attribution when reusing or redistributing the code components. Suggested attribution from the EULA:

> This code was derived from IEC 62351-4 within modifications permitted in the relevant IEC standard. Please reproduce this note if possible.
